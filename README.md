
# BuildOS - Construction Office Platform

BuildOS is an all-in-one operating system for construction companies, featuring project management, finance controls, workforce HR, and specialized marketplaces.

## 🚀 Quick Start

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Configure Environment**
   Create a `.env` file in the root:
   ```env
   API_KEY=your_gemini_api_key_here
   ```

3. **Run Development Server**
   ```bash
   npm run dev
   ```

## 🏗️ Deployment (Vercel)

1. Connect this repository to **Vercel**.
2. Set the **Environment Variable** `API_KEY`.
3. Build Settings are automatically detected (Vite).

## 🛡️ Key Features
- **AI Intelligence**: Gemini-powered cost prediction and risk analysis.
- **Enterprise ERP**: Multi-signature financial approvals and audit trails.
- **Site Management**: GPS-verified attendance and automated payroll.
- **Marketplaces**: Global procurement for materials and equipment.
